# MoviePilot 插件仓库

本仓库按官方 `MoviePilot-Plugins` 的 V3 目录组织，目前只包含 `SubscribeOverwatcher`（剧集守门员）。仓库根目录同时支持 GitHub 插件市场和本地插件源。

## 仓库结构

- `package.v3.json`：V3 插件市场索引，新增插件时在此登记。
- `plugins.v3/<插件目录>/`：各插件源码；当前为 `plugins.v3/subscribeoverwatcher/`。
- `tests/`：不连接真实数据库和站点的隔离行为测试。

## 安装来源

公开仓库地址：`https://github.com/yelantf/MoviePilot-Plugins`。在 MoviePilot 的 `PLUGIN_MARKET` 中追加该地址，保留已有地址。也可将本仓库的绝对路径加入 `PLUGIN_LOCAL_REPO_PATHS` 作为本地插件源。无需 GitHub 私有仓库令牌。

## 剧集守门员使用流程

1. 配置上述插件源后，在插件页选择 `SubscribeOverwatcher` 安装。配置页在尚未启用时也会显示可纳入的现有电视剧订阅；选中后打开“接管新增剧集订阅”和“纳入历史订阅”，一起保存即可接管该剧集。启用后新增的电视剧订阅由插件接管。既有剧集只有手动选择并保存“纳入历史订阅”后才会进入确认流程；插件记录它原来的暂停状态。已由插件管理的剧集不会重复出现在列表中。
2. 默认开启“全集种子也需确认”：插件会暂停待确认订阅，并在下载提交前拦截未批准的订阅下载。每 4 小时搜索一次目标季的单集 E01、识别集数覆盖全集的资源和疑似全集；候选按覆盖全集、疑似全集、E01 排列，新增订阅后也会尽快扫描。跨季资源不会进入候选。
3. 在配置页选一个候选，保存“只搜索并预览规则匹配”。留空“草稿规则 JSON”会使用候选识别出的质量、分辨率、特效、制作组和站点规则；也可修改 JSON 后重新预览。详情页列出当前搜索中通过与排除的资源及原因，全集资源排在前面。预览不修改订阅、不提交下载。
4. 检查预览结果后保存“确认已预览规则并恢复订阅”。预览必须在 30 分钟内生成，当前规则须仍匹配所选候选；若同时匹配多个集数覆盖全集的版本，选择全集候选时须先收窄规则并重新预览。确认后回填规则、恢复原本非用户暂停的订阅、安排一次缺集补搜，之后由 MoviePilot 正常追更。原本由用户暂停的历史订阅保持暂停。

预览只反映当次搜索结果和基础订阅筛选条件，不模拟 MoviePilot 最终下载排序、种子文件内容或未来新增资源。选择候选是选择**规则模板**，不是锁定这条种子。已批准订阅的实际下载在提交前仍按其当前质量、站点等规则复核；手动更改订阅规则不会撤销批准，旧预览会失效。

## 手动回刷已入库集数

1. 在 MoviePilot 中手动调整已批准订阅的筛选规则，也可以直接使用已回填的规则。
2. 在插件配置页选择这条已批准订阅，保存“按当前订阅规则预览可回刷资源”。详情页展示当前搜索中通过和排除的资源。此步只读，不修改订阅和媒体库。
3. 从通过的资源中选择一条，输入要重新下载的集数，如 `1,3-5`，保存“提交所选资源和集数重新下载”。插件会重新搜索同一资源，检查订阅身份、当前规则、资源唯一性和明确识别的集数，再调用 MoviePilot 单资源下载接口。预览超过 30 分钟、资源消失或规则变化时需重做预览。

集数由用户明确选择；插件不判断该集是否已入库，也不删除旧文件。下载器接受任务不等于媒体库已经完成替换；最终整理和文件覆盖仍由 MoviePilot 的配置与流程决定。相同种子已存在于下载器时，下载器也可能拒绝重复任务。

## 其他批准方式

- 关闭“全集种子也需确认”后，待确认订阅保持搜索资格。原订阅规则选中的种子，只有下载事件里识别出的资源集数覆盖当前季全部集数，且本次所选文件属于该种子时才会自动放行；即使本次只选择缺集，也按全集种子处理。分集种子仍被拦截。插件原先暂停的待确认订阅会恢复并补搜。总集数未知时不会放行。此判断依赖宿主当时识别出的季数、集数和订阅总集数，并不等同于下载完成后的文件核验。
- 可以选择待确认订阅并打开“直接批准，不回填 E01 规则”。保存后只记录批准、恢复订阅并补搜，质量、站点等筛选规则保持原值，也不会指定下载某个种子。
- 已批准且仍存在的订阅可选择“撤销批准并暂停”。插件会保留当前规则，暂停订阅、取消尚未启动的插件补搜任务，并恢复下载拦截。显式撤销优先于全集免确认开关；重新批准前，全集资源也不会自动下载。已提交的下载任务不会撤回。

每次保存配置只执行一种操作。用户在 MoviePilot 中手动修改已批准订阅的质量、站点等规则，不影响该订阅的批准状态；撤销时也不会覆盖这些修改。

候选与预览只保存种子标题、站点编号、规格、大小、识别集数和发现时间，不保存下载链接或站点 Cookie。单条订阅最多保留最近发现的 80 个候选，包括搜索结果中已消失的版本。每次规则预览最多展示 80 条通过和 40 条排除资源，页面显示完整计数。手动回刷仅记录最近 20 次已接受下载任务的资源标题、集数与提交时间。

## 边界

下载闸门依赖插件已安装、启用并成功注册事件处理器。停用、卸载、重载空窗或其它处理器在其后覆盖取消标记时，纯插件无法提供绝对下载保证。撤销批准时，已越过下载前事件的在途提交也无法回滚。手工直接下载资源不带订阅来源，不在本插件拦截范围。停用期间创建的订阅不会因重新启用而自动纳入管理，但可由用户从历史剧集列表中手动纳入。

本仓库仅提供插件源码，未修改 MoviePilot 主程序，也不会自动安装、启用或重载到运行中的实例。
