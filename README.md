# 剧集守门员（SubscribeOverwatcher）

剧集守门员是 MoviePilot V3 插件。它默认先暂停新剧集订阅，首次处理时核对一次媒体库并刷新目标季集数进度；已全集入库的订阅直接退出插件管理，仍留在 MoviePilot 的活动订阅中。其余订阅收集目标季资源候选；你可以预览规则后确认，也可以等订阅进度显示满时让插件保留原规则自动恢复。已有剧集订阅也可以手动纳入管理。

## 安装

在 MoviePilot 的 `PLUGIN_MARKET` 中加入 `https://github.com/yelantf/MoviePilot-Plugins`，保留原有插件源，然后安装 **剧集守门员**。也可以将本仓库的绝对路径加入 `PLUGIN_LOCAL_REPO_PATHS`，作为本地插件源。

## 开始使用

1. 在插件配置页打开 **接管新增剧集订阅**，点击 **保存设置**。之后新增的电视剧订阅会进入待确认状态。
2. 如需管理已有订阅，在 **纳入历史剧集** 中多选剧集，点击 **纳入所选剧集**。已纳入的剧集不会重复出现在选择列表中。
3. 在数据页查看候选的集数、站点、资源标题和大小；点击候选行中对应站点的 **配置·站点名** 或 **下载·站点名**，都会进入配置页并选中该站点的版本。也可以在配置页手动选择剧集及版本，再调整质量、分辨率、特效、包含和排除条件，点击 **预览匹配**。配置页会自动滚动到结果，直接列出通过与排除资源、排除原因统计、生效条件和各阶段耗时。
4. 如需指定硬盘，在 **下载目录** 中选择对应目录卡片的资源根目录；留空保留订阅原保存目录。设置页的预览会显示每条通过资源的完整预计下载路径。
5. 核对预览后，点击 **确认并恢复**。插件回填候选规格和选中的资源根目录，并安排一次缺集补搜。分类子目录只用于预览，实际下载由 MoviePilot 根据当前目录配置处理。预览超过 30 分钟、规则或目录选择变化时，需要重新预览。

如果只想下载选中的候选种子，在数据页点击 **下载·站点名** 进入配置页，或直接在配置页选择剧集和版本；核对标题、大小及站点详情后，点击 **一次性下载整个种子**，再点 **确认整包下载**。两个数据页按钮都只负责选中候选，不会立即提交。配置页可为这次任务选择下载目录，留空则沿用订阅原目录或系统默认目录。插件会从本轮或历史内存搜索结果中找所选种子的真实下载链接；找到唯一匹配且带下载地址的资源就直接交给 MoviePilot。内存地址已丢失时，只重查所选站点，核对候选 ID、详情链接、媒体身份和订阅范围后再提交。跨季合集会下载所有季，不会只选目标季；下载器接受任务时，订阅规则、批准状态和追更状态不变。之后订阅进度显示已完成全部目标集时，插件自动直接批准并恢复，原规则不变。没有可核对的详情链接，或重查后仍找不到唯一且带下载链接的同一资源时，不会提交；可手动扫描该剧集以更新候选。部分站点的短时签名链接失效时，MoviePilot 下载链可能只刷新同一资源的链接。

新增或手动纳入的普通剧集在首次进度检查或候选扫描前核对一次媒体库：根据目标季实际缺集更新总集数、缺失集数；已齐集则解除插件造成的暂停并退出插件管理，用户原本手动暂停的订阅仍保持暂停。此过程不会触发订阅完成，完成时机由 MoviePilot 和其他插件决定。洗版订阅及增强版待定 `P` 不做这项核对。核对失败会记入插件日志，候选扫描继续，后续定期扫描不重复查库。订阅缺失集数或状态变化后约 2 秒检查进度，整理完成事件也会触发检查，另每 15 分钟复核一次。此后的自动批准只依据订阅进度；已由用户暂停的历史订阅、增强版待定 `P` 和显式撤销的订阅不会被自动恢复。进度可能在订阅下载任务提交时就显示已满，早于整理入库。

候选选择项和详情页都会显示易读大小及精确字节数。详情页只合并标题、字节大小、集数和解析规格相同的跨站资源；配置页仍逐站选择。**选择候选本身不会立即下载；一次性下载需另点下载按钮。**

数据页只展示管理状态、候选和提交记录；规则匹配与回刷资源的预览结果只在配置页展示。

候选列表和搜索缓存都会合并保留历史资源，并标明候选是否在最近一次扫描中找到。站点链接只用于打开种子详情，不是下载器需要的种子下载链接。后一次扫描未再次找到的种子，只要当前进程还保有它的真实下载地址，仍可直接整包下载；插件重启或重载后只恢复脱敏的历史记录，确认下载会尝试单站重查。在配置页选中候选后，可直接点 **候选规则确认** 标题旁的 **重新扫描此剧集** 更新候选；扫描后需重新核对并确认下载。没有候选的剧集，可在配置页靠上的 **手动扫描已纳入剧集** 卡片选择并扫描。

扫描结果只展示目标季的首集、明确包含首集的多集资源、整季及含目标季的跨季候选，不与系统搜索的全部资源逐条一致。副标题“第1-3集”若被 MoviePilot 识别为 E01–E03，会列为 **含首集的多集资源**，并显示实际覆盖集号；只含 E06 等后续集数的资源不会进入候选。主标题、副标题中的“全5集”“5集全”“Complete”等字样，以及站点“完结”标签，可作为整季线索；没有明确集号覆盖全集时，显示 **疑似整季（集数待核实）**，不会据此自动放行全集下载。规则预览还会按所选站点、搜索方式和筛选条件限制结果。

规则面板采用订阅卡片的常用选项，常见质量默认使用内置选项；包含、排除条件支持输入关键字或自定义正则，制作组也可单独选择。确认前的 **站点范围** 可选候选站点、从当前启用的站点中自选多个站点，或不限站点；自选站点框可输入名称，按包含关系筛选后多选。下方 **站点** 栏同步显示名称。候选是规则模板，自选范围可以不含候选原站点，但预览必须有符合规则的资源才能确认。

**规则组**默认保留原订阅或宿主默认选择，也可选择 **不使用规则组**。宿主会把空规则组列表解释为使用默认组，因此插件在确认时给该订阅指定一个合法的全放行组。自动候选扫描跳过规则组；预览默认应用订阅或系统规则组，并比较跳过规则组的结果。规则组过滤全部可匹配资源时，预览会提示并自动选择不使用规则组，确认后才回填。

候选每 **4 小时**扫描一次，新增剧集会尽快首次扫描。扫描和预览共用搜索缓存，**预览有对应范围的缓存就复用，不设超龄限制**；点击 **重新搜索并预览**时主动刷新。定期扫描仍会搜索并更新默认站点范围的最新结果，同时在缓存中合并保留历史资源；预览只把最新结果计入通过和排除统计，历史候选单独列出。“不限站点”使用 MoviePilot 当前默认搜索站点范围；预览会列出有缓存和缺缓存的站点，只补搜缺失站点，再合并各站点的最新结果。复用最新空结果时，结果旁提示并提供手动重新搜索按钮。数据页候选单独持久保存，跳转到设置页不清缓存。**搜索缓存持久保存，重启、重载或更新后继续复用预览结果**；最多 256 组、磁盘合计 64 MiB。一组是同一订阅媒体身份与站点选择范围的一份搜索结果，大小随结果数量变化；容量满时淘汰较旧结果并记录日志。批准成功、停用插件或删除订阅时也记录清理原因。磁盘缓存保存最新及历史筛选事实、媒体分类和查询验证，不保存 Cookie 或种子下载凭据；内存中的完整搜索结果可供当前进程整包下载。候选、规则预览和页面不展示种子下载链接或 Cookie。回刷提交仍重新搜索核实当前资源。

保存设置、预览和刷新页面不会额外触发全量候选扫描。新增或纳入订阅后，15 秒内合并扫描对应订阅；重启时不重复扫描最近 4 小时已扫描的订阅。新搜索使用“剧名 S07”这样的带季关键词，未命中时最多尝试一个本地名称，再验证一次原订阅搜索策略并补收跨季合集。带季查询限制名称数量，原订阅搜索沿用宿主别名策略；缓存预览不发出站点请求。

**手动扫描已纳入剧集**可选择任意仍在管理中的待确认剧集，包括尚无候选的剧集。点击 **扫描所选剧集**立即重新搜索这一条，完成后更新下方版本列表和预览缓存，不触发其他剧集或下载补搜；进行中的候选扫描不会重复启动。旧规则预览会清除，确认前需要按新结果重新预览。同站点同详情链接的种子在候选和预览中只展示一次，并合并本轮不同搜索结果提供的副标题和标签，保留合集线索。

扫描候选、版本选择和规则预览显示**做种人数及免费/促销**，选定版本后也会单独显示。合并版本按站点分别展示这些信息；它们是最近搜索时的状态，重新搜索可更新。旧记录或站点未提供的数据显示“未知”，0 做种明确显示为 0 人。

每条订阅独立扫描。插件不再读写系统订阅的共享失败预算，也不保存跨订阅失败冷却；同一站点在本条订阅本轮失败后，后续搜索词和翻页不再重试，其他订阅仍各自尝试。实际请求继续经过宿主站点访问计数和流控，同站请求开始间隔默认随机 10–20 秒，站点配置更长时遵守更长间隔；正在进行的插件请求不重叠，插件间隔及在途等待最多 60 秒，过长等待仅在本条订阅本轮暂缓。宿主真实访问额度的等待仍由宿主管理。

候选规则确认中的 **确认后的订阅搜索词** 只有 **沿用原订阅搜索方式** 和 **使用剧名＋季号搜索词** 两项，后者如“Show S01”。默认沿用原订阅；原搜索正常完成但未召回要验证的资源、剧名加季号查询已召回时，预览自动切换到剧名＋季号搜索词。候选原站点不在自选范围内时，以所选站点中符合规则的资源验证搜索词。预览只统计最终选择的方式召回的资源，确认后才回填订阅 `keyword`，按需从 IMDb ID 搜索改为标题搜索。原搜索失败或缓存缺少验证记录时不自动切换，可重新搜索或手动选择剧名＋季号搜索词再预览；直接批准仍保留原设置。搜索词或规则组被预览自动切换时，对应选择框显示警示色边框和文字提示。

失败不会触发即时重试或冷却到期补扫；下一次 4 小时扫描、手动扫描或主动重新搜索重新独立尝试。一次订阅搜索内，相同站点、实际搜索词、类型和页号复用本轮结果，减少英文站点名称转换或别名造成的重复请求。页面区分真实请求和同轮复用次数；站点明确限流及自身访问额度仍由宿主流控处理。

候选列表合并历史记录，不另设历史条数上限；规则预览和回刷预览各只保留最新一次，每份最多展示 80 条通过、40 条排除资源。**确认后的候选和确认预览保留 24 小时，满 24 小时后由下一次扫描清理**，批准状态与订阅规则继续有效。后续回刷预览从自身生成时间起保留 24 小时，再由扫描清理。订阅删除后，下次扫描清理对应记录与缓存。

## 其他常用操作

| 需求 | 配置页操作 | 结果 |
| --- | --- | --- |
| 不想逐条确认全集种子 | 关闭 **全集种子也需确认** | 符合原订阅规则、明确覆盖目标季全集的资源可自动通过；分集仍需确认。 |
| 不回填候选规格 | 在 **直接批准** 中选择订阅，点击 **批准并保留原规则** | 保留订阅现有筛选规则并恢复追更。 |
| 暂停已批准订阅 | 在 **撤销批准** 中选择订阅，点击 **撤销并暂停** | 保留规则，重新拦截后续订阅下载。 |
| 重新下载已入库集数 | 选择已批准订阅，点击 **预览可回刷资源**；再选资源、填写如 `1,3-5` 的集数并提交 | 向 MoviePilot 提交所选资源和集数；插件不会删除旧文件。 |

**保存设置**只保存长期设置；各分区的操作按钮会同时保存当前设置并执行该操作。执行后配置页会刷新选择项并显示结果。

插件默认在 MoviePilot 所在时区的每天 09:00 发送一条待确认订阅汇总，消息类型为 **插件**。可在配置页调整时间或关闭通知。

例如，选择 `/PtResourceDir2/bt/downloads`，预览可显示 `/PtResourceDir2/bt/downloads/电视剧/国产剧`，确认回填的仍是 `/PtResourceDir2/bt/downloads`。未选择新目录时，也会按订阅原目录或 MoviePilot 默认目录预览。

候选搜索、识别集数、去重与合并、规则回填、下载拦截、数据保存和使用边界见[设计与实现说明](docs/subscribeoverwatcher.md)。
