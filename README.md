# MoviePilot 插件仓库

本仓库按官方 `MoviePilot-Plugins` 的 V3 目录组织，目前只包含 `SubscribeOverwatcher`（剧集守门员）。仓库根目录同时支持 GitHub 插件市场和本地插件源。

## 仓库结构

- `package.v3.json`：V3 插件市场索引，新增插件时在此登记。
- `plugins.v3/<插件目录>/`：各插件源码；当前为 `plugins.v3/subscribeoverwatcher/`。
- `frontend/subscribeoverwatcher/`：配置页和详情页的 Vue 源码；编译产物随插件放在 `plugins.v3/subscribeoverwatcher/dist/`。
- `tests/`：不连接真实数据库和站点的隔离行为测试。

修改 Vue 界面后，在 `frontend/subscribeoverwatcher/` 执行 `npm ci`、`npm test` 和 `npm run build`，再提交生成的 `dist/` 文件。

## 安装来源

公开仓库地址：`https://github.com/yelantf/MoviePilot-Plugins`。在 MoviePilot 的 `PLUGIN_MARKET` 中追加该地址，保留已有地址。也可将本仓库的绝对路径加入 `PLUGIN_LOCAL_REPO_PATHS` 作为本地插件源。无需 GitHub 私有仓库令牌。

## 剧集守门员使用流程

1. 配置上述插件源后，在插件页选择 `SubscribeOverwatcher` 安装。配置页在尚未启用时也会显示可纳入的现有电视剧订阅；可多选历史剧集，同时打开“接管新增剧集订阅”后点击“纳入所选剧集”。启用后新增的电视剧订阅由插件接管；既有剧集只有手动选择并执行纳入操作后才会进入确认流程。插件记录它们原来的暂停状态，已纳入管理的剧集不会重复出现在列表中。
2. 默认开启“全集种子也需确认”：插件会暂停待确认订阅，并在下载提交前拦截未批准的订阅下载。每 4 小时通过 MoviePilot 按媒体身份搜索各季，并在搜索结果处理中筛选包含目标季的资源；跳过全局搜索规则组，也不传入这条订阅的站点和筛选规则。候选包括识别集数覆盖全集、包含目标季的跨季资源、标题疑似整季和单集 E01，按上述顺序排列；新增订阅后也会尽快扫描。媒体身份不符或季数列表不包含目标季的资源不会进入候选；列表保留过去扫描发现的资源，不能据此判断资源现在仍可用。
3. 在配置页选一个候选和站点范围，再点击“预览匹配”。默认只用所选站点；选择“不限站点”会清除订阅的站点限制，其他候选规格照常回填。留空“草稿规则 JSON”会使用候选识别出的质量、分辨率、特效、包含和站点规则；制作组与自定义标识都能在标题中验证时会组合成包含规则。候选未识别出的属性保留订阅原值；文本规则可在 JSON 中显式填写 `null` 清空，站点使用 `[]` 表示不限、`null` 表示保留原站点。可编辑的回填字段为质量、分辨率、特效、包含、排除和站点，并不覆盖订阅的所有字段。详情页列出当前搜索中通过与排除的资源及原因，全集资源排在前面。预览核对基础订阅条件和站点，不模拟订阅自己的规则组；正式追更仍按订阅规则组过滤。预览不修改订阅、不提交下载。
4. 检查预览结果后点击“确认并恢复”。预览必须在 30 分钟内生成，当前规则须仍匹配所选候选；若同时匹配多个集数覆盖全集的版本，选择全集候选时须先收窄规则并重新预览。确认后回填规则、恢复原本非用户暂停的订阅、安排一次缺集补搜，之后由 MoviePilot 正常追更。原本由用户暂停的历史订阅保持暂停。

插件启用后默认每天在 MoviePilot 所在时区的 09:00，以“插件”消息类型发送一条待确认订阅汇总，包含总数、订阅 ID、剧名和季数。没有待确认订阅时也会发送 0 条汇总。可在插件配置中调整发送的小时、分钟，或关闭“每天推送待确认订阅汇总”。

插件配置页会列出当前已纳入管理的剧集和确认状态；详情页提供完整表格，包括手动纳入或新增接管的来源、待确认或已批准状态及当前订阅进度。尚未纳入的历史剧集按进度从少到多排序，选择项直接显示集数，方便优先选择零进度或低进度订阅。普通剧集显示 MoviePilot 的已入库集数（总集数减缺失集数）；洗版订阅显示洗版完成进度。总集数或进度字段缺失时显示“订阅进度未知”。这不是下载器内的任务或文件数量。

通过 MoviePilot 正常升级插件时，与仍存在的订阅对应的待确认、已批准、候选版本和回刷记录继续从同一个 `gate_state` 插件数据键读取；升级不会因版本号变化清空这些记录。卸载时若同时清除插件数据，则无法由插件恢复。

“标题疑似整季”表示资源标题含“全集”“Complete”“Pack”等标记，且标题及集数解析没有明确指出它只从后续集数开始；例如标题写有 `S01E11` 或已识别为 E11/12 的资源不会进入候选。升级时会清理旧状态中的同类误判。“未识别具体集号”表示标题解析没有提供集号。目标总集数取自订阅记录（通常由媒体资料填充），资源集号来自种子标题解析，均不等于种子文件内实际包含的集数。预览只反映当次搜索结果和基础订阅筛选条件，不模拟 MoviePilot 最终下载排序、种子文件内容或未来新增资源。选择候选是选择**规则模板**，不是锁定这条种子。已批准订阅的实际下载在提交前仍按其当前质量、站点等规则复核；手动更改订阅规则不会撤销批准，旧预览会失效。

跨季资源只在识别季列表包含目标季时纳入候选，显示覆盖的季数并标注“各季集数待核实”。MoviePilot 提供的集号列表没有按季拆开，因此插件不会把跨季资源标为目标季“识别集数覆盖全集”。为使宿主返回跨季资源，扫描不再向搜索链传入单季缺集限制，可能比过去检索更多同剧其他季的结果；插件会在搜索结果处理中筛掉不含目标季的资源。关闭“全集种子也需确认”时的自动整季放行仍要求资源只覆盖目标季；跨季资源需要手动确认订阅规则，且不能用于手动指定集数回刷。

候选搜索复用 MoviePilot 的媒体识别和 `SearchChain.process`，显式传入空规则组，插件没有独立的站点搜索实现。搜索链返回值的去重键包含站点名、标题和描述，因此不同站点的记录仍是独立条目。插件用站点 ID、标题、大小的摘要合并历次候选，同一候选更新最后发现时间并保留首次发现时间。详情页与规则预览会将标题、大小、集数和解析规格一致的跨站资源合并展示为一行，保留每个站点的详情链接；配置页仍逐站选择候选。确认时默认只回填所选站点，也可选“不限站点”，把订阅站点设为空列表，同时照常回填候选的质量、分辨率、特效和包含规则。标题或大小变化可能形成另一条候选；这不是种子文件哈希去重。

## 手动回刷已入库集数

1. 在 MoviePilot 中手动调整已批准订阅的筛选规则，也可以直接使用已回填的规则。
2. 在插件配置页选择这条已批准订阅，点击“预览可回刷资源”。详情页展示当前搜索中通过和排除的资源。此步只读，不修改订阅和媒体库。
3. 从通过的资源中选择一条，输入要重新下载的集数，如 `1,3-5`，点击“提交所选资源和集数”。插件会重新搜索同一资源，检查订阅身份、当前规则、资源唯一性和明确识别的集数，再调用 MoviePilot 单资源下载接口。预览超过 30 分钟、资源消失或规则变化时需重做预览。

集数由用户明确选择；插件不判断该集是否已入库，也不删除旧文件。下载器接受任务不等于媒体库已经完成替换；最终整理和文件覆盖仍由 MoviePilot 的配置与流程决定。相同种子已存在于下载器时，下载器也可能拒绝重复任务。

## 其他批准方式

- 关闭“全集种子也需确认”后，待确认订阅保持搜索资格。原订阅规则选中的种子，只有下载事件里识别出的资源集数覆盖当前季全部集数，且本次所选文件属于该种子时才会自动放行；即使本次只选择缺集，也按全集种子处理。分集种子仍被拦截。插件原先暂停的待确认订阅会恢复并补搜。总集数未知时不会放行。此判断依赖宿主当时识别出的季数、集数和订阅总集数，并不等同于下载完成后的文件核验。
- 可以选择待确认订阅，点击“批准并保留原规则”。执行后只记录批准、恢复订阅并补搜，质量、站点等筛选规则保持原值，也不会指定下载某个种子。
- 已批准且仍存在的订阅可选择后点击“撤销并暂停”。插件会保留当前规则，暂停订阅、取消尚未启动的插件补搜任务，并恢复下载拦截。显式撤销优先于全集免确认开关；重新批准前，全集资源也不会自动下载。已提交的下载任务不会撤回。

“保存设置”只更新长期设置；各分区的操作按钮会同时保存当前设置并执行对应的一次性操作。执行后配置页保持打开，刷新选择项并在当前分区显示结果；详情页只显示当前管理状态，不重复显示上次操作结果。用户在 MoviePilot 中手动修改已批准订阅的质量、站点等规则，不影响该订阅的批准状态；撤销时也不会覆盖这些修改。

候选与预览只保存种子标题、站点编号、规格、大小、识别集数、发现时间和经过清理的站点详情页地址，不保存种子下载链接或站点 Cookie。配置页选中候选后可点击对应站点名称打开详情；详情页和规则预览也把链接放在各自的站点名称上，资源标题均为普通文本。没有安全地址的站点名称显示为普通文本。旧候选需再次被扫描发现后才会补上详情链接。单条订阅最多保留最近发现的 80 个候选，包括搜索结果中已消失的版本。每次规则预览最多展示 80 条通过和前 40 条排除资源，页面显示完整计数。手动回刷仅记录最近 20 次已接受下载任务的资源标题、集数与提交时间。

## 边界

下载闸门依赖插件已安装、启用并成功注册事件处理器。停用、卸载、重载空窗或其它处理器在其后覆盖取消标记时，纯插件无法提供绝对下载保证。撤销批准时，已越过下载前事件的在途提交也无法回滚。手工直接下载资源不带订阅来源，不在本插件拦截范围。停用期间创建的订阅不会因重新启用而自动纳入管理，但可由用户从历史剧集列表中手动纳入。

本仓库提供插件源码及配置界面的编译产物，未修改 MoviePilot 主程序，也不会自动安装、启用或重载到运行中的实例。
