# MoviePilot 插件仓库

本仓库按官方 `MoviePilot-Plugins` 的 V3 目录组织，目前只包含 `SubscribeOverwatcher`（剧集守门员）。仓库根目录同时支持 GitHub 插件市场和本地插件源。

## 仓库结构

- `package.v3.json`：V3 插件市场索引，新增插件时在此登记。
- `plugins.v3/<插件目录>/`：各插件源码；当前为 `plugins.v3/subscribeoverwatcher/`。
- `tests/`：不连接真实数据库和站点的隔离行为测试。

## 安装来源

公开仓库地址：`https://github.com/yelantf/MoviePilot-Plugins`。在 MoviePilot 的 `PLUGIN_MARKET` 中追加该地址，保留已有地址。也可将本仓库的绝对路径加入 `PLUGIN_LOCAL_REPO_PATHS` 作为本地插件源。无需 GitHub 私有仓库令牌。

## 剧集守门员使用流程

1. 配置上述插件源后，在插件页选择 `SubscribeOverwatcher` 安装并启用。配置后新增的电视剧订阅由插件接管；既有订阅保持原样。
2. 照常新增电视剧订阅。默认开启“全集种子也需确认”：插件会暂停新订阅，即使新增事件晚到，下载提交前的同步事件也会拦截未确认的新订阅。每 4 小时搜索一次待确认订阅对应季的单集 E01，保存不同站点和规格的候选；新增后还会尽快安排一次扫描。
3. 在插件详情页查看候选及最后发现时间。到插件配置页选择一个 E01 候选，打开“确认回填规则并恢复订阅”开关，保存配置。插件根据该候选回填质量、分辨率、特效、制作组和站点；缺少某项可识别规格时该项会清空。确认后恢复订阅、安排一次缺集补搜，之后由 MoviePilot 正常追更。

## 其他批准方式

- 关闭“全集种子也需确认”后，待确认订阅保持搜索资格。原订阅规则选中的种子，只有下载事件里识别出的资源集数覆盖当前季全部集数，且本次所选文件属于该种子时才会自动放行；即使本次只选择缺集，也按全集种子处理。分集种子仍被拦截。插件原先暂停的待确认订阅会恢复并补搜。总集数未知时不会放行。此判断依赖宿主当时识别出的季数、集数和订阅总集数，并不等同于下载完成后的文件核验。
- 可以选择待确认订阅并打开“直接批准，不回填 E01 规则”。保存后只记录批准、恢复订阅并补搜，质量、站点等筛选规则保持原值，也不会指定下载某个种子。
- 已批准且仍存在的订阅可选择“撤销批准并暂停”。插件会保留当前规则，暂停订阅、取消尚未启动的插件补搜任务，并恢复下载拦截。显式撤销优先于全集免确认开关；重新批准前，全集资源也不会自动下载。已提交的下载任务不会撤回。

每次保存配置只执行一个批准或撤销动作。用户在 MoviePilot 中手动修改已批准订阅的质量、站点等规则，不影响该订阅的批准状态；撤销时也不会覆盖这些修改。

候选只保存种子标题、站点编号、规格、大小和发现时间，不保存下载链接或站点 Cookie。单条订阅最多保留最近发现的 80 个候选，包括搜索结果中已消失的版本。选择候选只是选择**规则模板**，不会直接下载该 E01 种子；补搜和追更仍由 MoviePilot 按已回填的规则匹配。

## 边界

下载闸门依赖插件已安装、启用并成功注册事件处理器。停用、卸载、重载空窗或其它处理器在其后覆盖取消标记时，纯插件无法提供绝对下载保证。撤销批准时，已越过下载前事件的在途提交也无法回滚。手工直接下载资源不带订阅来源，不在本插件拦截范围。启用期间创建的电视剧订阅会一直等待确认；若停用期间新增了订阅，再次启用后的定期扫描也可能将其纳入待确认列表。

本仓库仅提供插件源码，未修改 MoviePilot 主程序，也不会自动安装、启用或重载到运行中的实例。
